# Portable ASR

Self-hosted speech-to-text service with an OpenAI-compatible API. Runs Whisper on CPU or NVIDIA CUDA, with optional transcript cleanup through a local or external LLM. Android and desktop clients receive the final transcript; they do not need their own cleanup configuration.

## Quickstart

Start with CPU transcription and no cleanup. On Ubuntu/Debian, install Python 3.10+ and venv support (Python 3.12 is a useful starting point):

```bash
sudo apt update
sudo apt install git python3 python3-venv
git clone https://github.com/ImAngelParraga/portable-asr.git
cd portable-asr
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp config/profiles/cpu.env.example .env
chmod 600 .env
```

Edit `.env` and replace `change-me` with a token generated by `.venv/bin/python -c 'import secrets; print(secrets.token_urlsafe(32))'`. Then load the profile and start:

```bash
set -a
. ./.env
set +a
export ASR_MODEL_CACHE_DIR="$PWD/.model-cache"
.venv/bin/python asr_server.py
```

Run from the checkout directory. `.env` is a shell-compatible file that you explicitly load; the application does not load it automatically. The writable cache override avoids requiring access to `/opt` for local development. First transcription downloads the model and can take longer; internet access is needed until weights are cached. The requirements currently include NVIDIA runtime packages even in CPU mode; no GPU or driver is needed for CPU inference.

From a second terminal in the checkout:

```bash
set -a
. ./.env
set +a
curl --fail http://127.0.0.1:9000/health
curl --fail -H "Authorization: Bearer $ASR_BEARER_TOKEN" \
  -F model=whisper-1 -F language=en \
  -F 'file=@/path/to/audio.wav;type=audio/wav' \
  http://127.0.0.1:9000/v1/audio/transcriptions
```

Replace the audio path with an existing recording. Health checks confirm the process is running; a successful transcription confirms model loading and inference.

## Connect a client

- [OpenVoiceIME](https://github.com/ImAngelParraga/OpenVoiceIME): Android voice keyboard.
- [OpenVoiceDesktop](https://github.com/ImAngelParraga/OpenVoiceDesktop): Linux GNOME Wayland and Windows dictation.

Use the server base URL, the same bearer token, and `whisper-1`. Refresh the client's model list for optional engines. Whisper's actual checkpoint is selected by `ASR_MODEL_SIZE` on the server. A short optional transcription `prompt` supplies vocabulary context, not cleanup instructions.

For another PC or phone, use the [deployment guide](docs/setup.md): `127.0.0.1` only works on the server itself, and Android release builds require HTTPS.

## Models and cleanup

Start with Whisper `base` on CPU (`int8`). Try `small` for greater accuracy if latency permits, or `large-v3` on CUDA (`float16`). Optional Qwen3-ASR and Parakeet engines need additional setup.

Cleanup is disabled by default. The local cleanup profile uses `unsloth/Qwen3.5-9B-GGUF:Q4_K_M`; an external OpenAI-compatible LLM is also supported. See [model choices and cleanup](docs/models-and-cleanup.md) for hardware tradeoffs, setup commands, sources, and a ready-to-use [generic cleanup prompt](config/cleanup-prompt.txt).

## Configuration and API

Copy one profile from [config/profiles](config/profiles) and load it as shown above, or use it as the service installer's environment source. [config/asr.env.example](config/asr.env.example) lists the main runtime settings.

| Endpoint | Purpose |
| --- | --- |
| `GET /health` | Process status; no authentication |
| `GET /v1/audio/models` | Enabled transcription models |
| `POST /v1/audio/transcriptions` | Audio to final transcript |
| `POST /v1/text/postprocess` | Cleanup text, optional `instruction` |
| `POST /v1/chat/completions` | Compatible transcript cleanup |
| `POST /v1/llm/chat/completions` | Non-streaming local/proxied LLM chat |

All `/v1/*` routes require bearer authentication. [Dictation formatting](docs/dictation.md) documents optional built-in voice controls. [Advanced configuration](docs/advanced.md) covers Qwen, Parakeet, model residency, GPU sharing, and diagnostic audio retention.

## Development and privacy

```bash
.venv/bin/python -m unittest discover -s tests
scripts/secret-scan.sh
```

Tests mock inference and need no GPU or model downloads. Audio history is off by default. Keep tokens, private endpoints, model caches, and recordings out of Git. [Release checks](docs/release.md) and the [public/private boundary](docs/public-boundary.md) describe publication hygiene.
